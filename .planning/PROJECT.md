# anhoder的进阶日志

## Overview
Static blog site at [anhoder.com](https://anhoder.com) — a PHP/Go/PostgreSQL backend development technical blog built with Hexo (Pisces theme).

## Tech Stack
- **SSG**: Hexo
- **Theme**: Pisces (NexT family)
- **Deploy**: GitHub Pages (static HTML)
- **Analytics**: Google Analytics + Baidu Tongji
- **Libraries**: KaTeX (math), highlight.js (code), Velocity.js (animation)
- **No backend**: Pure static site, all dynamic features are client-side JS

## Existing Features
- Blog posts, tags, archives, friends page
- Visual effects: snow, canvas-nest, clock, wave, fireworks, love, peace (under `media/js/`)
- Live2D character
- Excalidraw embeds
- KaTeX math rendering
- Code syntax highlighting

## Current Goal
Add 10 pure-frontend niche tools/widgets across various domains, targeting the backend developer audience. All tools must be client-side only (no backend dependency).

## Audience
Chinese-speaking backend engineers interested in PHP, Go, PostgreSQL, distributed systems, and system design.
